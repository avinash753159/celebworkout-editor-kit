II. The rule the system is built on

Order every stage by what it costs to find a defect there. Nothing expensive runs until everything cheap has passed. Every complaint in the voice note — narrator echo, mid-sentence bites, one source over-mined, no workout, no brand — is detectable in text, for free, before a frame exists.

0

INVENTORY free · ~10 min

Walk dossier/<subject>/sources/. Transcribe every media file that has no captions. Index every caption file. Emit what is actually in each one: duration, named exercises, people, dates, quotable complete-thought windows.

Gate No research task may open until the inventory is green. Nothing may be generated that the inventory says already exists.

Runs: pipeline/inventory.py → manifest/inventory_<subject>.json · faster_whisper, already installed

1

SOURCE free · 1–2 h unattended

Acquire to 10–15 sources. Scene-detect, identity-pass, then cut candidate bites on word-level timings so every bite is a complete thought. Build the bite bank with a per-source ledger.

Gate ≥10 sources · ≥8 min of usable bite time · no source over 20% of it · every bite identity-verified · no bite starts or ends mid-sentence

Runs: pipeline/bitebank.py · reuses detect_shots, word_times, verify_pool

2

SCRIPT LOOP pennies · ~30 min

Braid outline, then five drafts in parallel, each a different angle. Every draft read by a first-time viewer simulation, critiqued for structure, and swept for language tics. Score, keep the winner, graft the best beats off the rest. Repeat until the reader stops complaining.

Gate reader-sim clean twice running · zero echo against the bite bank · runtime projection 20 min ±2 at measured WPM · every movement in the programme named on screen · no narration block that only describes the picture

Runs: story-planning · creative-writing-modes · reader-sim · story-review · llm-writing · echo_check.py

3

Assemble the whole film as audio: free draft narration, the real bites, the music. No picture. This is the film's spine and it is listenable end to end.

Gate real-voice ≥40% · music-beat share ≈2.5% · runtime 20 min ±1 · no bite clipped mid-thought · no interviewer filler

VI. Build order

  1. pipeline/inventory.py — Stage 0~1 h · highest ROI

    Transcribe-if-missing, index, report what each asset contains. Would have printed "MENSHEALTH.mp4 — 8 named exercises" on day one and saved this entire week. Reusable for every celebrity, forever.

  2. gates/ — the standard, made executable~3 h

    One machine-readable standard file, then a gate per row of the table in §III. Each returns pass/fail plus evidence. Validated by running them against the two rejected films — a suite that passes either one is wrong.

  3. pipeline/bitebank.py — Stage 1~3 h

    The stage that has never existed. Complete-thought cutting on word timings, identity pass, per-source ledger. This is what puts the subject on screen.

  4. The script loop — Stage 2~2 h

    Five parallel drafts, reader-sim, review, tic sweep, score, iterate. The skills are installed; this is the harness that runs them in a loop and keeps score.

  5. Teams on the board~2 h

    Provision the six teams against the live controller, wire the Python as tools, prove review_request_changes closes the loop without a human. Do the one-team smoke test first — if it stalls waiting for a click, the overnight design changes.

~11 hours of build. After that a film is roughly four hours, nearly all of it unattended, and the failures happen where they are free.
