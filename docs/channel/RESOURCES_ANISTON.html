NEW — the highest-leverage tool for your #1 blocker

claude-video

github.com/bradautomates/claude-video

Lets Claude actually watch a video instead of reasoning from a title or search snippet: pulls native captions first (free, instant), falls back to yt-dlp + ffmpeg frame extraction and Whisper transcription (needs a Groq or OpenAI key) when captions don't exist, then hands back a timestamped transcript plus frames.

Why this matters: real voice sits at 3.4% against a 40% gate (GOAL.md §7) — the single blocking item in this whole production. Every hunt field naming a real interview (InStyle, Katie Couric Media, the Refinery29 Ingber piece, GMA/how2fit coverage) is a candidate: point claude-video at it, get the real transcript back, and either confirm exact wording (restore it as a REAL-V bite) or learn it doesn't say what was assumed — same discipline that already found the fabricated Rolling Stone quote and the wrong byline in this film's own research (GOAL.md §15).

Install: /plugin marketplace add bradautomates/claude-video in Claude Code, or npx skills add bradautomates/claude-video -g elsewhere.

Remotion templates + docs/resources

remotion.dev/templates remotion.dev/docs/resources remotion.dev/showcase

Two pieces worth pulling from the official gallery specifically: the TikTok template (word-by-word animated captions) for burned-in captions on the film's 4 REAL-V bite rows and any future DEMO rows with speech — matches THE_STANDARD.html's existing rule that captions sit bottom-third, bold sans, all caps. And Stills (dynamic PNG/JPEG generation) for batch-rendering the 33 CARD rows straight from the JSON manifest instead of hand-building each one in an editor — the manifest already has the exact copy and duration for every card.

docs/resources also lists remotion-subtitle (captioning/styling utilities) and remotion-animate-text (text animation helpers) as standalone libraries, if a full template feels heavier than needed for a specific card.

Recommended build order

  1. Start from the Blank template (remotion.dev/templates) or a Next.js starter if the render needs to be a hosted app rather than a local CLI render.
  2. Clone the specific template files needed (see table above) from reactvideoeditor/remotion-templates into the project — don't install the whole repo.
  3. Build one React component per CARD sub-type (numeral-stat, name-reveal, timeline, act-break, end-card) driven by props, then generate one <Composition> per row directly from manifest/shotlist_jennifer_aniston.json — the JSON already has the exact copy, duration, and beat context for every card, so this is a data-driven render, not 33 hand-built graphics.
  4. For the 35 REAL-A + 20 DOC archival rows, apply the Cinematic Effects Ken Burns component uniformly — it's a direct implementation of the push-in spec already written into every one of those rows' note field.

Audio Editor

Five continuous-narration blocks, not sixteen per-beat clips. Never crossfade. Full mix rules and the exact ElevenLabs-ready text are on the Audio Plan and Transcript tabs — this section is about what tooling to actually run.

ElevenLabs — a working, tested pattern already exists in this project

pipeline/hems_narrate.py is the real template to copy, not a generic integration written from scratch. Verified from the file itself: narrates block-by-block (a failed block costs one block, not the whole render; each block gets an exact measured duration for the EDL); uses ElevenLabs' previous_text/next_text parameters to keep prosody continuous across joins; butt-joins with 30ms edge fades and never crossfades (a crossfade shortens total audio ~0.3s per junction — this caused audible A/V drift on an earlier film in this project). Voice used previously: nPczCjzI2devNBz1zQrb ("Brian"), model eleven_turbo_v2_5 (0.5 credits/char). Key at elevenlabs_key.txt, repo root.

For this film: adapt it to read the 5 files in dossier/jennifer_aniston/tts/ (CNB-1.txt through CNB-5.txt) instead of one script file — same block-per-file, never-crossfade rule.

ALREADY INSTALLED in this project

creative-writing-skills

github.com/haowjy/creative-writing-skills

A skill/agent package for fiction craft — prose technique, scene mechanics, story planning, editorial review, character simulation, reader simulation — coordinated by a "muse" agent across three phases (explore/plan, draft/revise, knowledge maintenance).

Already sitting in .claude/skills/ in this exact repo, apparently installed for an earlier or parallel project and never used on this one:

  • story-review — editorial critique of a draft. A second, independent pass alongside (not instead of) the exemplar-quality craft tournament already applied to this film's cold open, B-story payoff, and close.
  • reader-sim — simulates an audience reader's real-time reaction. Useful for stress-testing the (now-cut-to-9s) cold open, or any future beat pacing question.
  • writing-principles — reader-reward model and failure-mode diagnostics, generic across fiction and, with adaptation, narration.
  • creative-writing-craft — prose rhythm, sensory grounding, POV/voice technique.
  • character-sim, story-planning, llm-writing, information-hierarchy, and others — see .claude/skills/ for the full list (22 sub-skills total).

Built for fiction, not documentary narration — filter every suggestion through that, but reader-sim and story-review are close enough to be worth a trial run.
