What MrBeast got, what Hemsworth got, and what happens next

The MrBeast film was produced audio-first against a 472-line written standard, nine pipeline stages and seven machine-checked format gates. The Hemsworth film was produced picture-first against none of them. This document reconstructs the method exactly, measures the current film against it, and specifies the rebuild.

The difference between the two films is not talent, budget or compute. It is that MrBeast passed through nine stages and four owner gates, and Hemsworth passed through four stages and none. Every fault you have named — the stretched images, the missing subject, the narrator restating quotes — is a stage I skipped, and each one had a script already written to catch it.

The quote blocks are the trap

Ten blocks are marked quote and read as if they were evidence. Every one is the synthetic narrator speaking someone else's words over a generated image. That is simultaneously the V1 failure (no archival voice), the R4 failure (narration restating a bite), and the reason a documentary about Chris Hemsworth contains no Chris Hemsworth. One defect wearing three costumes.

2 — The film has no footage of its subject

Not an oversight in execution; there was no stage that could have produced any. The V12 architecture was built for MrBeast precisely to stop hunting footage and generate everything. Carrying it to Hemsworth unchanged meant nothing in the pipeline ever looked for the man. SOURCES.md planned five video sources; no code was written to download, cut or place them.

Partially fixed today. pipeline/hems_footage.py now cuts real footage into existing slots, frame-exact, cropping broadcast furniture geometrically rather than masking it. The GMA insert is built: 289 frames, 1920×1080, 24 fps, all ABC branding removed, his own voice at the emotional peak.

3 — Men's Health is not Chris Hemsworth

The second download was to be the workout evidence. On inspection the man lifting has full sleeve tattoos, and SOURCES.md line V4 describes the source accurately as "Luke Zocchi demonstrating the actual method." Men's Health also burns exercise lower-thirds into the lower-left, inside any 16:9 crop that keeps the action. Rejected. Substituting a presenter for the subject would have been worse than the absence.

Every fault traces to the same root: picture was made before sound was approved, so nothing could be checked while it was still cheap to change.

III. The MrBeast method, stage by stage

Nine stages. Each names the file that implements it, so none of this has to be rebuilt — only pointed at a new subject.

  1. Build the sound bank before the script existssoundbank.py

    Every utterance in every source transcribed with faster-whisper — punctuated, with word-level timestamps — and indexed to manifest/soundbites.json. The module's own rationale: "the script is written TO the material rather than the material hunted to match the script, so the bank exists before the script does." YouTube auto-caption VTTs are explicitly rejected: no punctuation means no sentence boundaries, which means no way to honour "a bite plays a complete thought".

    Each record carries id · source_id · speaker · t0 · t1 · duration · chapter · topic_tags · text · status. The status field is the verification state — MrBeast's bites reached transcript_and_frames_verified before use.

  2. Run a second research pass that tries to prove the first wrongdiet_dig.py

    The V1–V4 research concluded there was "no verified diet in the public record". That conclusion was false — the Rogan interview contains a first-person diet discussion at 87–91 minutes and the Airrack documentary films the training itself. A dedicated adversarial pass found it. The first research pass is assumed wrong until something has tried to break it.

  3. Write the production standard, and make it bindingOWNER GATE

    472 lines covering: the one-sentence story; a creative filter for what stays and what goes; the click package and thumbnail brief; a second-by-second contract for the first ninety seconds; runtime percentages per act; a five-question chain every chapter must pass; research database requirements; the sound map; mix targets; the graphic system; the retention audit; the three-level ending.

  4. Write the script to the material, in three columns§7

    Picture/evidence | Speech | Sound — and each column must add different information. Never show, narrate and caption the same fact. Every sequence expresses because → decision → partial solution → new problem, using causal connectors, with chronology that has no causal effect removed.

  5. Run two echo detectors as blockersecho_check.py · repetition_check.py

    echo_check catches narration restating the clip beside it: a number echo (a figure from the bite reappearing in adjacent narration) is a hard failure; a phrase echo (a shared content bigram across the boundary) is a warning. It ships with a known-bad control — py -3.12 pipeline/echo_check.py V3 — so the detector itself is tested.

    repetition_check catches a different defect: narration repeating itself across the film. It reports concept frequency, content trigrams appearing in two or more blocks, and the same figure restated in two or more blocks.

  6. Audit every bite against the actual audiobite_audit.py · word_times.py

    For each bite, transcribe a padded window with word timestamps and report START MID-SENTENCE, END MID-SENTENCE and TAIL DRIFT — the last sentence introducing a subject absent from the rest of the cut. It prints the exact word times of every sentence boundary near the edges, so a corrected in/out point is chosen rather than guessed.

  7. Build and deliver the radio editOWNER GATE · mrbeast_radio.py

    The pivot of the whole method. It parses the three-column master, resolves bite ids through the soundbite manifest, generates free draft narration one contiguous run at a time, fits the EDL to measured TTS rather than estimated durations, enforces the gates, and renders a reviewable radio MP4. No paid TTS and no picture edit are used here.

    The standard states this is "a mandatory approval gate for every new CelebWorkout video, not just a MrBeast review step." The audio-only review asks: is every person introduced? Does each chapter change the situation or our understanding? Does every 2–4 minutes produce a partial payoff? Are any facts repeated? Do quotations reveal character rather than merely inform? Can the reversals be felt without visuals? Does the ending answer the opening anomaly? Where does attention drift?

  8. Validate the timeline before a single image is madeedl.py · qc_v11.py

    edl.py has no I/O at all — no ffmpeg, no subprocess, no file access. That is deliberate: it makes every gate a pure function of the cut list, and therefore unit-testable. qc_v11.py runs the pure validators and, given a rendered file, adds V7: the render matches the timeline.

  9. Only now, picture — with three separate rejection stagesbite_windows · clean_windows · apply_verdicts

    bite_windows.py finds the picture that is the bite, in sync, by enumerating the uninterrupted runs inside each bite's span — because a 22-second bite crosses the podcast's own camera cuts, and a naive window lands half on the host. That is precisely how Rogan and Bartlett ended up in a film they are banned from.

    clean_windows.py OCRs the bands where burned-in text lives and rejects any window containing third-party captions, watermarks, location cards or channel logos. The V6 cut shipped "who's gonna puke first?", www.Bandicam.com and BYRON BAY, AUSTRALIA before this existed.

    apply_verdicts.py requires human eyes-on identity verdicts, one file per reviewer so two reviewers cannot race, matched on a stable sid@t0 key. A window is drawable only if both gates pass: subject verified and no text. And blame_shots.py traces any flagged shot in the finished cut back to its source file by perceptual hashing, because the review flags shot numbers and the allow-list holds file names.

Why V7 is missing from that list

V1–V6 and V8 are pure timeline validators. V7 is the render check — it compares the finished file against the EDL within SYNC_TOLERANCE and therefore needs a rendered artefact, so it lives in qc_v11.py rather than edl.py. Note also that qc_v11.report() refuses to compare an unfitted EDL against a render: if fit_run_durations() has not replaced placeholder narration durations with TTS-measured ones, the comparison is meaningless and the tool says so instead of passing.

V. The conflict you must resolve

V1 requires real archival voice to carry at least 40% of runtime. Your YouTube copyright rule requires one clip per source video, no clip over ten seconds, no repeats. These cannot both hold.

The arithmetic
QuantityValue
Current runtime767.5 s
V1 requirement at 40%307.0 s of archival voice
Maximum per clip under your rule10 s
Clips therefore required31
Distinct sources therefore required31

Maximum achievable voice ratio50 s = 6.5%

MrBeast resolved this by using fourteen sources — and the note in SOURCES.md records exactly that reasoning: "The previous film took 8 bites from a single Rogan episode; under this rule it needed 14 sources." Hemsworth's research found five. Four options:

OptionEffectCost
A. Find 25 more video sourcesV1 holds unchangedDays of research; most Hemsworth Alzheimer's material traces to the same few originals, so this may not exist
B. Replace V1 with an evidence ratio — archival voice plus on-screen primary documents ≥ 40%Print quotes rendered as source_highlight count as evidence. This is what SOURCES.md already proposes: "a print source needs no clip at all"New gate to write; ~1 hour
C. Lower V1 for narration-led filmsHonest but weakens the gate that would have caught this film's central failureFree
D. Shorten the film to ~2 minutesArithmetically satisfies V1Not a film

My recommendation: B

An evidence ratio measures what V1 was actually protecting — that the film shows you the record rather than asserting it — while staying inside your copyright rule. A Vanity Fair sentence marked on the page is primary evidence in a way a synthetic narrator reading it is not. It also makes the source_highlight and headline_over effects load-bearing rather than decorative, which is what they were built for. I would keep V1 as a separate, lower floor — real archival voice ≥ 5% — so "no human voice at all" remains impossible.

VII. Story architecture

The thesis, from SOURCES.md

Chris Hemsworth carries two copies of APOE4 — eight to ten times the population risk of Alzheimer's. His grandfather had it. His father Craig, 71, has it now. In 2025 he drove his father around Australia to visit the places tied to Craig's memories, while Craig was losing them.

He is not a man told about a risk. He is a man watching his own future happen to his father, and filming it.

That reframes the fitness material completely: the training is not vanity and not longevity theatre, it is the one lever he has been told might matter, applied by a man who has seen where the road goes.

The five-question chain

Every chapter must answer all five before the script locks: entry question · discovery · status change · partial payoff · exit question. A chapter that cannot answer all five is not a chapter; it is material.

Narration rules, §8

  • Conversational 135–165 WPM · fast montage 165–185 · emotional and medical passages 110–140
  • Typical sentence 8–18 words; a consequential statement occasionally 2–7
  • A new narrative beat every 20–45 seconds; a meaningful pause of 0.5–2 s after major lines
  • Narration may establish context, connect cause to consequence, compress time, direct attention to evidence, or frame the next question
  • Narration must not describe visible action or paraphrase a quotation the viewer just heard
  • Source voices carry confessions, bodily experience, promises, contradictions, high-value numbers and character-revealing language

Six available layers — narration, primary dialogue, production sound, music, atmosphere, designed effects — of which only one or two may dominate at a time. Every music cue requires a documented entrance, development, peak, exit and handoff. No cue continues merely because the track is long.

Mix requirements, §11

  • Narration at 48 kHz in the assembly pipeline. The current Hemsworth audio is 44.1 kHz — a deviation to correct.
  • Music ducking beneath complex speech begins in the 6–14 dB range, adjusted by ear
  • Reduce percussion and melodic density beneath explanations
  • Preserve J-cuts and L-cuts for source dialogue; starting overlap 0.5–3 s where structurally useful
  • Audio joins stay butt-joined with edge fades — never crossfade chunks, which shortens the result ~0.3 s per junction and accumulates into audible A/V drift
  • Check on phone speakers, at quiet playback, and in mono
  • Final target ≈ −14 LUFS integrated, −1 dBTP, with dialogue intelligibility taking precedence
  • Silence is created by subtraction and room tone, not dead digital silence

IX. Picture specification

Evidence priority, §12

actual event footage  >  primary evidence  >  specific contextual B-roll
   >  purposeful reconstruction/animation  >  metaphor  >  generic stock

The current film sits almost entirely in the fifth band. Every shot must prove, explain, locate, humanise, contrast, foreshadow, recall or transition — and cut when the idea, power relationship, evidence, speaker, emotion or comprehension changes, never to create arbitrary motion.

X. Definition of done

  • Three-column master script exists
  • Every chapter passes the five-question chain
  • Radio edit passes without visuals, and is signed off
  • Evidence ratio (archival voice + on-screen primary documents) ≥ 40%
  • Real archival voice ≥ 5% — no film with zero human voice can ship
  • No single bite over 30 s; no clip over 10 s; one clip per source
  • Each chapter has a documented sound instruction
  • Every music cue has entrance, development, peak, exit and handoff
  • Every factual claim maps to the research database
  • Every 30-second block passes the retention audit
  • Opening anomaly is answered at factual, character and universal levels
  • Opening image and sound return with changed meaning
  • Three thumbnail variants pass the 10% size test
  • Final 2% bridges naturally to another channel video
  • V9: every source image is 16:9 within 1.5% before the renderer sees it
  • Narration at 48 kHz; master ≈ −14 LUFS, −1 dBTP; checked on phone, quiet and mono
  • Music attribution present in the video description (Scott Buckley, CC BY 4.0, per cue)
  • No third-party broadcast furniture visible in any frame
