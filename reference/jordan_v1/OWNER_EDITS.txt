INSTRUCTION 4.2  "elevelabs brian deosn't work - can you use
                  https://github.com/abus-aikorea/voice-pro"

    DONE, with one substitution I want to be explicit about.

    Voice-Pro itself could not be used directly: it is a Gradio web app that
    needs an NVIDIA GPU, ~20GB of disk and a browser, and documents no CLI or
    API — so it cannot be driven headlessly across 46 narration blocks.

    What Voice-Pro IS, is a front end onto a set of engines. Its own README
    ranks KOKORO as the strongest (#2 on the HuggingFace TTS Arena). Kokoro
    ships as an ONNX model that runs locally on CPU with no key, no quota and
    no network — a better fit for a batch build than any hosted API.

    So: all 46 narration blocks are now Kokoro, voice "am_michael".
      · installed kokoro-onnx (NOT kokoro — it needs spacy, which does not
        build on Python 3.14)
      · models in jordan_v1/models/kokoro/
      · measured 158 wpm against the channel's own measured 161 wpm
      · auditioned and rejected: am_onyx (flatter), am_eric (193 wpm, too
        fast), bm_george (British, wrong register)

    No ElevenLabs, no edge-tts, anywhere in the film.

    a shadow AND a surface tint that lightens as the plane rises. Levels 2, 4

    linked: extreme contrast between a towering uppercase display face (Anton)
