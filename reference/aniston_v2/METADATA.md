## Copyright position

- One clip per source video. Never two. Enforced by a uniqueness assertion.
- Nine seconds maximum, against a ten second ceiling.
- No moment used twice.
- Every rights holder credited on screen for the whole duration of its clip.
- Two sources were reviewed and **dropped** rather than used: one built on
  midriff before/after comparisons (body scrutiny is what the film argues
  against), one that was only screenshots of article text.
- The thumbnail frame comes from a source used nowhere else in the film, so it
  is still one use of one source.
- Music is original. Nothing here can be Content-ID claimed on audio.

## Known weaknesses

- **360p archive.** YouTube would only serve format 18 for these sources.
  It is upscaled with lanczos, sharpened and grain-matched, and it reads as
  archive, which it is — but it is soft next to the graphics.
- **Three of nine movements have no real demonstration.** The one-clip-per-
  source rule ran the demo footage out at six. Those three carry a name plate
  over a still. More demo sources would fix it.
- **No interview audio is used.** Every clip is picture-only under narration.
  Using the sources' own audio would need a per-clip audio pass and would
  change the mix; it is the obvious next improvement.
- **Chapter timings in this file are estimates** — read them off the final cut.
